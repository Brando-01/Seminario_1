# Datos

Pega los datos originales dentro de estas carpetas. Las rutas se declaran en `configs/experiment_1_ieee.yaml` y `configs/experiment_2_paysim.yaml`.

- IEEE-CIS: `data/raw/ieee_cis/`
- PaySim: `data/raw/paysim/`

Mientras esas carpetas estén vacías, la configuración usa temporalmente como respaldo los CSV que ya están en la carpeta superior del seminario. No se duplican ni modifican.

No se deben versionar CSV originales, matrices procesadas ni grafos generados.
